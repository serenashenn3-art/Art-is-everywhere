# 输入示例

## 场景：用户上传橘猫照片，要求生成名画融合

### 用户输入原文
```
用行走的艺术技能，我上传了我家橘猫的照片，帮我生成名画融合的作品。
```

### 附带信息
- **宠物照片描述**：一只成年橘色英国短毛猫，圆滚滚的身材，白色爪子和下巴，金黄色眼睛，粉色鼻子，毛发蓬松柔软
- **偏好**：用户喜欢古典风格，没有指定特定名画

### AI 识别的触发条件
✅ 用户明确提到"行走的艺术"
✅ 有宠物照片/照片描述
✅ 需求是名画与宠物结合的创作

### AI 应执行的操作
1. 根据宠物类型（猫咪）从名画数据库中推荐 3 幅最合适的画作（如：宫娥、人间乐园风格、两个弗里达）
2. 等待用户选择或随机选择一幅
3. 使用对应的提示词模板生成图像
4. 按照输出格式规范展示画作信息
